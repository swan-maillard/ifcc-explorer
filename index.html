      How to read it

      The compiler doesn't go straight from C to assembly. It first cuts each function into basic blocks, short lists of instructions that always run together. A block ends with a jump, a test, a switch or a return. The graph in the middle shows these blocks and the arrows between them.

      In the IR, names with a $ are the variables of the C code and names with a # are temporary values. The graph is shown after our four optimisation passes (constants computed in advance, unused temporaries removed, empty and unreachable blocks skipped), so some lines of C don't leave anything behind.

      Hover or click a line or a block to see where it comes from and what it becomes. Step runs the IR one instruction at a time, and each variable is in the same stack slot as in the real assembly. For every program on this page, the exit code is the same as with GCC, on both backends.
